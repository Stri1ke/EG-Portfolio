GAME UI/UX

SKINS BARON

Игровой ивент · UI/UX и визуальный дизайн

Интерфейс ивента Skins Baron в тематике CS2 спроектирован так, чтобы игрок сразу видел свой прогресс, следующий шаг и доступные награды. Структура экранов следует за логикой заданий. Сетка коллекции помогает сравнить прогресс по штампам, отдельные карточки позволяют выполнять ежедневные задания в любом порядке, а шкала показывает текущий и заблокированные этапы еженедельной цепочки. Для карточки коллекции проработаны четыре варианта — до начала, в процессе, награда доступна и награда получена. У каждого варианта есть обычное состояние и состояние при наведении.
