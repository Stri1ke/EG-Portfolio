GAME UI/UX

Tower Game

Интерфейс для игры Tower

Для Tower Game разработаны игровой интерфейс и визуальный стиль с акцентом на читаемость игрового поля и узнаваемость проекта. В основе интерфейса — вертикальная сетка, где синие ячейки формируют игровое поле, а жёлтые акценты выделяют выигрыш и отдельные клетки. Ключевой визуал объединяет массивный логотип с заклёпками и стилизованного персонажа-птицу в тактической экипировке. Тёмная палитра связывает интерфейс и ключевой визуал, а жёлтые акценты выделяют главное в каждом из них.
