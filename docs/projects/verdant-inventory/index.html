Сокровищница Рошана

Интерфейс для ивента

Интерфейс «Сокровищницы Рошана» помогает игроку понять, сколько шагов он прошёл, сколько опыта нужно до следующего и когда можно открыть кейс. Изометрическая карта показывает весь маршрут, а компактная панель прогресса — текущее состояние и доступное действие. Для панели проработаны варианты для авторизации, накопления опыта, открытия кейса и завершения квеста. В отдельной сетке наград собраны полученные скины и ещё не открытые кейсы.
