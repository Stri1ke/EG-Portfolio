GAME UI/UX / DEMO

Tower Game

Интерфейс управления миссией

EN

A game interface and visual identity were designed for Tower Game, with a focus on making the board easy to scan and giving the game a recognizable look. The interface is built around a vertical grid, with blue tiles defining the play area and yellow accents drawing attention to winnings and highlighted tiles. The key visual pairs a bold, riveted wordmark with a stylized bird mascot in tactical gear. The dark palette connects the interface and the key visual, while the yellow accents give both a clear focal point.

RU

Для Tower Game разработаны игровой интерфейс и визуальный стиль с акцентом на читаемость игрового поля и узнаваемость проекта. В основе интерфейса — вертикальная сетка, где синие ячейки формируют игровое поле, а жёлтые акценты выделяют выигрыш и отдельные клетки. Ключевой визуал объединяет массивный логотип с заклёпками и стилизованного персонажа-птицу в тактической экипировке. Тёмная палитра связывает интерфейс и ключевой визуал, а жёлтые акценты выделяют главное в каждом из них.
